# One Snowflake, One Silent Cabin Morning

Entry for make.fun's "One Emoji, One Dream Vacation" bounty
(`u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35`).

`main.py` writes exactly one emoji to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output`): a single snowflake (❄️), standing in for a
silent cabin morning — snow falling past the window, no meetings, no
notifications, nowhere to be. One character, nothing else.

Run it:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
